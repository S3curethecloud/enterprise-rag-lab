# Enterprise Secure RAG Lab

A phase-gated educational tutorial for learning Retrieval-Augmented Generation and Secure RAG from first principles.

This repository is designed to teach an engineer how RAG works, how to implement it, how to attack weak implementations, and how to design enterprise security boundaries around retrieval and generation.

## Core Principle

> The LLM does not grant access to enterprise data. Retrieval authorization occurs before context reaches the model.
