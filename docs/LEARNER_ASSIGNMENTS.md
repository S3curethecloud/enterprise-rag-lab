# Secure RAG Learner Assignments

The coding labs in this repository demonstrate how the architecture works.

The learner assignments are designed to test whether you understand **why** it works.

## Learning Method

Every phase follows this learning cycle:

```text
READ
  ↓
BUILD
  ↓
BREAK MENTALLY
  ↓
RESEARCH
  ↓
EXPLAIN
  ↓
TEACH IT BACK

The goal is not memorizing commands.

The goal is being able to reason about the architecture without looking at the source code.

Three Learning Layers
README

Answers:

What should I understand?

LAB

Answers:

Can I build and observe it?

ASSIGNMENT

Answers:

Can I explain, defend, challenge, and remember it?

Course-Wide Security Rule

The LLM never grants access to enterprise data. Authorization occurs before retrieved context reaches the model.

Final Outcome

A learner who completes all fourteen assignments should be able to:

explain RAG without relying on buzzwords;
distinguish relevance from authorization;
reason about ingestion and query trust boundaries;
explain secure context construction;
defend grounded abstention;
identify output-security risks;
design behavioral security evaluations;
explain why application layers must not bypass controls;
draw the complete Secure RAG architecture from memory.
